# Content notes — personal website refresh (October 2026)

## Direction

This website is a personal home, not a job-site landing page or an academic publication list. The tone should feel natural, curious and human. Keep the original minimal design, avoid a dramatic hero slogan and don't turn every interest into a credential.

## What changed

- **Home:** Replaced repetitive grades, supervisor/availability cards, and placeholder copy with a short personal introduction, research and code, actual GitHub repositories, and space for everyday interests.
- **About:** Rewrote in first person, separated degree facts from narrative, and added a simple section about music, coffee, cooking, technology and places. No invented personal achievements.
- **Research:** Explained cospectrality and the thesis accessibly. Removed unverified claims of newly proved theorems, classified graph families, active manuscripts and automatic proofs from computational searches.
- **Projects:** Replaced imagined optimizers and dead/generic links with public repository entries, grouped by research, code and side projects. Distinguish completed coursework from experimental tools and learning notebooks.
- **Writing:** Replaced seven generic hypothetical titles and a posting promise with short editorial notes connected to real work and the coffee notebook.
- **Contact:** Removed promises to reply within 48 hours, job-market availability claims, unverified relocation statements and a list of narrowly targeted roles. Keep communication approachable.
- **Miscellany:** Kept the independent coffee recipe book and its visual identity. Corrected a few misleading measurements and removed advice to shake hot milk in a sealed jar.
- **Meta and navigation:** Updated descriptions so mathematics is visible without claiming it's the only thing here. Renamed the /blog navigation label to Writing; old route remains stable.
- **Documentation:** Replaced the generic framework README with documentation about this actual site.

## Editorial guardrails

1. Prefer "I", short paragraphs, and ordinary wording.
2. Do not invent publications, rankings, affiliations, internships, awards, project metrics or outcomes.
3. Name a tool as used only if public source or another reliable record supports it.
4. Distinguish learning, prototype, coursework and academic research. A failed cospectral-mate search is not a proof of spectral determination.
5. Avoid temporary promises and dated phrases such as "first post coming next week" or "available immediately".
6. Don't present any private repository as public source code without an explicit decision to publish it.
7. Correct verified academic facts in `src/lib/profile.ts` and update tests when they change.
8. Keep this site's unique voice; don't substitute generic marketing copy.
